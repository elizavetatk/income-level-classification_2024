# Классификация уровня дохода 

Учебный проект по дисциплине «Методы и средства интеллектуального анализа данных в экономике» (ноябрь 2024). Классификация уровня дохода на датасете Adult Census Income: логистическая регрессия, отбор признаков, подбор гиперпараметров по Log Loss.

## Цель проекта

По имеющимся признакам предсказать уровень дохода группы людей: **более 50K** или **менее 50K**.

## О данных

Источник: [Adult Census Income Dataset](https://archive.ics.uci.edu/dataset/2/adult) (UCI Machine Learning Repository).

Признаки:

| Признак | Тип | Описание |
|---|---|---|
| `age` | continuous | Возраст |
| `workclass` | categorical | Статус занятости (Private, Self-emp-inc, Federal-gov и др.) |
| `fnlwgt` | continuous | Количество людей в группе по переписи |
| `education` | categorical | Уровень образования (Bachelors, HS-grad, Masters и др.) |
| `education-num` | continuous | Число пройденных ступеней образования |
| `marital-status` | categorical | Семейное положение |
| `occupation` | categorical | Область занятости |
| `relationship` | categorical | Взаимоотношения (Wife, Husband, Own-child и др.) |
| `race` | categorical | Раса |
| `sex` | categorical | Пол |
| `capital-gain` | continuous | Прирост капитала |
| `capital-loss` | continuous | Потеря капитала |
| `hours-per-week` | continuous | Количество рабочих часов в неделю |
| `native-country` | categorical | Родная страна |

**Целевая переменная:** `salary` — `<=50K` или `>50K`.

## Что внутри

1. **Импорт и предобработка данных** — обработка пропусков и выбросов.
2. **Проверка гипотезы** о влиянии признака `education` на целевую переменную.
3. **Укрупнение признака `education`** — объединение категорий и проверка влияния нового признака на результат.
4. **Визуализация** зависимости между целевой переменной и статусом образования.
5. **Обработка признаков** в зависимости от их типа и подготовка данных для классификатора.
6. **Разделение выборки** на обучающую и тестовую.
7. **Отбор признаков** в модель.
8. **Построение классификатора** на основе логистической регрессии.
9. **Валидация и подбор гиперпараметров** (`GridSearchCV` с `scoring='neg_log_loss'`).
10. **Оценка качества модели** и **оценка важности признаков**.

## Бизнес-метрика

**Log Loss (логарифмическая функция потерь)** — основная метрика проекта.

**Обоснование выбора:** требуется максимизировать качество вероятностной классификации. Log Loss штрафует модель не только за неверные предсказания, но и за низкую уверенность в правильных — это критически важно, когда нужно не просто определить, превышает ли доход человека 50K, но и оценить степень уверенности модели в этом предсказании.

**Интерпретация:** чем ближе к 0, тем выше качество. Базовый уровень — 0.5.

## Результаты

**Log Loss = 0.3429**
- Значение ниже базового уровня (0.5).
- Модель уверенно предсказывает вероятности: ошибки не сопровождаются ложной уверенностью.

**ROC-AUC = 0.8897**
- Показатель близок к 0.9 — высокое качество бинарной классификации.
- Модель хорошо различает людей с доходом менее 50K и более 50K.

### Наиболее значимые признаки

| Признак | Влияние на доход |
|---|---|
| `education_Preschool` | наличие только дошкольного образования — сильный негативный фактор |
| `occupation_Priv-house-serv` | работа в частном доме — негативный фактор |
| `workclass_Without-pay` | неоплачиваемая работа — негативный фактор |
| `capital-gain` | прирост капитала — значимо связан с высоким доходом |
| `marital-status_Married-AF-spouse` | семейное положение — связано с более высоким доходом |

### Содержательные выводы

- **Образование.** Наличие только дошкольного образования (Preschool) значительно снижает вероятность высокого дохода. Более высокие уровни образования (`education-num`, `5th-6th`) связаны с повышением вероятности.
- **Занятость.** Неоплачиваемая работа (`Without-pay`) и работа в частном доме (`Priv-house-serv`) — сильные негативные факторы. Руководящие должности (`Exec-managerial`), наоборот, положительно влияют на доход.
- **Финансовые показатели.** Прирост капитала (`capital-gain`) значимо связан с высоким доходом.
- **Семейное положение.** Состоящие в браке имеют более высокий доход, статус «собственный ребёнок» (`Own-child`) влияет отрицательно.

### Итог

Модель демонстрирует хорошее качество и пригодна для решения поставленной задачи. Выделенные признаки логически обоснованы, что подтверждает адекватность модели.
